## About the Department

The Department of Computer Science and Engineering (CSE) at Lords Institute of Engineering & Technology (LIET), Hyderabad, focuses on developing strong computing fundamentals, practical engineering skills, problem-solving abilities, research capabilities, and professional competence.

Established in **2003**, the department supports students in exploring computer science through academic learning, technical projects, collaborative development, research, competitions, and industry-oriented activities.

This GitHub repository serves as a shared digital space for the department's academic resources, student projects, research initiatives, technical documentation, and open-source contributions.

Our goal is to encourage a culture in which students and faculty learn together, build meaningful solutions, document their work, and contribute to the wider technology community.

## How to Contribute 🤝

Students can contribute by submitting academic projects, improving documentation, sharing useful learning resources, and collaborating on approved repositories.

### Project Submission Workflow

1. **Explore:** Visit the appropriate LIET departmental repository.
2. **Fork:** Create your own fork of the repository.
3. **Prepare:** Organize your project in the designated directory and include a clear README.
4. **Commit:** Commit your changes with a meaningful message.
5. **Submit:** Open a Pull Request (PR) for review.
6. **Review:** Address feedback and make any requested corrections.
7. **Merge:** The project is merged after the authorized reviewer approves it.

### Project Organization

For repositories using the approved batch structure, place your project under the relevant directory:

`Project/batch-2022-2026/`

Confirm the currently applicable batch directory before submitting.

### Pull Request Guidelines

- **PR title format:** `<Project Name> | <Roll Number>`
- Include the project name and a brief explanation of its purpose.
- Mention all team members by their full names in the PR description.
- Include setup instructions, dependencies, usage examples, and screenshots where relevant.
- Ensure that the project runs as described and does not contain credentials, API keys, or other sensitive information.
- Respond to review comments and update the PR when corrections are requested.

### Suggested Project README Structure

Every submitted project should include:

- Project title and overview
- Problem statement
- Objectives and proposed solution
- Technology stack
- Features
- Installation and setup instructions
- Usage instructions and screenshots
- Team members and contributions
- References, where applicable

Please follow the repository's contribution instructions and any additional requirements published by the department.

## Community Guidelines 🌱

We aim to maintain a respectful, inclusive, and collaborative learning environment.

All contributors are expected to:

- Communicate respectfully and constructively.
- Give credit to original authors and sources.
- Submit original work or clearly acknowledge third-party work.
- Respect intellectual property, licensing, privacy, and institutional policies.
- Avoid uploading confidential information, credentials, or unauthorized personal data.
- Provide constructive feedback during project reviews.
- Follow the applicable repository contribution guidelines and Code of Conduct.
